# Порівняння ділянок · спайк №74

## Варіант 1. Панель поверх карти

На широкому екрані компактна панель відкривається ліворуч поверх карти й закриває пріоритети та маршрути. На телефоні панель відкривається знизу. Контури гексагонів відповідають кольорам у заголовках колонок.

```text
┌────────────────────────────────────────────────────┐
│ Порівняння 2/3     Згорнути       Карта             │
│ ● А ×  ● Б ×                                       │
│ Показник        ● А      ● Б      ◇ Контур А        │
│ Загальна        72 ▬     81 ▬               ◇ Б     │
└────────────────────────────────────────────────────┘
```

«Порівняти» доступне від двох ділянок. Кожен числовий результат має шкалу від 0 до 100. Видалення до однієї ділянки повертає панель до вибору.

## Варіант 2. Модальне вікно

```text
┌─────────────────────────────────┐
│ Порівняння 2/3                × │
│ Показник           А         Б  │
│ Загальна оцінка   72        81  │
│ Мобільність       64        88  │
│                                 │
│ Повернутися до карти            │
└─────────────────────────────────┘
```

Модальне вікно дає таблиці більше ширини. Щоб змінити вибір, користувач повертається до карти зі збереженим набором, додає або видаляє ділянку й знову відкриває порівняння. Окремий екран також вміщує більше показників, але додає перехід між вибором і порівнянням. Для спайку рекомендована панель, оскільки можна додати третю ділянку під час перегляду оцінок.

## Дані й питання для рев’ю

Демо порівнює загальну оцінку й категорії за однакових поточних ваг. У перевіреній версії бекенду `GET /points/{point_id}` повертає одну точку за ID, а `GET /hexagons/{h3_id}` повертає оцінки. Для показника об’єктів поблизу потрібно узгодити межу підрахунку, категорії об’єктів і API, яке повертає зіставні дані для всіх ділянок.

На рев’ю команда обирає панель або модальне вікно для тікетів реалізації.
